# The Polite Scraper

A Python scraper that collects book information politely from the Books to Scrape practice website.

## Target Classification

* **Target website:** https://books.toscrape.com/
* **Target type:** Public web-scraping practice sandbox.
* **Scope:** Only the first 3 catalogue pages, containing 60 books.
* **Data collected:** Title, product URL, price, availability, rating, description, source page, and fetch time.
* **Permission:** ToScrape states that Books to Scrape is a safe place for beginners to practise web scraping.
* **Robots check:** No robots file found. The `/robots.txt` request returned `404 Not Found`.
* **Reason:** This collection is appropriate because the website was specifically created for practising web scraping.

I will not reuse this code on another site without checking its rules and terms first.
